# OpenNeural Electron Shell

This directory contains the Electron desktop application shell that hosts the frontend renderer and manages the lifecycle of the Python FastAPI backend process.

## Setup and Installation

Ensure you have Node.js (v18 or newer) installed.

From the `electron` directory, install dependencies:
```bash
npm install
```

## Running Electron in Development Mode

To start the Electron application in development mode:

```bash
npm run dev
```

This starts the Electron main process, opens the Chromium-based desktop window, and boots/connects to the local Python FastAPI sidecar backend process.

## IPC Communication

OpenNeural utilizes Electron IPC (`ipcMain` and `ipcRenderer` bridged securely via `contextBridge` in `preload.ts`) to manage secure bridge interactions:
- Initializing local workspace directory paths.
- Exposing the dynamic port and local auth secrets generated by the backend process.
- Sending application logging updates.

### Testing IPC Communication

To test IPC bridges during development, you can use the built-in diagnostic logging or trigger IPC communication manually:
1. Open the Chromium Developer Tools within the running Electron window (`Cmd+Option+I` on macOS or `Ctrl+Shift+I` on Windows/Linux).
2. Use the window context properties exposed via the preload script (e.g., `window.api` or similar context-bridged APIs) to invoke methods and verify IPC responses in the console.

## Packaging and Building the App

To compile and package the app for your local operating system platform:

```bash
npm run build
```

This executes `electron-builder` under the hood, packaging the compiled React frontend, Node main process, and bundling/referencing the packaged Python backend executable according to the specifications in `electron-builder.config.js`.

The packaged artifacts are output to the `dist/` directory.
